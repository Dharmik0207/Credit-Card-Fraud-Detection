# Credit-Card-Fraud-Detection
🚀 Machine Learning project for detecting fraudulent credit card transactions using imbalanced dataset techniques and predictive models.
## 📌 Overview  
Credit card fraud is a major financial issue, and detecting it effectively is a challenging task due to highly imbalanced data (fraud cases are very rare).  
This project explores **data preprocessing, visualization, feature engineering, and machine learning models** to accurately classify fraudulent transactions.  

---

## 📂 Dataset  
- Dataset: [Credit Card Fraud Detection Dataset (Kaggle)](https://www.kaggle.com/mlg-ulb/creditcardfraud)  
- Contains transactions made by European cardholders in September 2013.  
- Total transactions: **284,807**  
- Fraud cases: **492 (~0.17%)**  

---

## ⚙️ Tech Stack  
- **Python 3**  
- **Pandas, NumPy** – Data analysis & preprocessing  
- **Matplotlib, Seaborn** – Data visualization  
- **Scikit-learn** – Machine learning algorithms  
- **Imbalanced-learn (SMOTE, undersampling)** – Handling imbalanced data  

---

## 🧠 Models Implemented  
- Logistic Regression  
- Decision Tree  
- Random Forest  
- XGBoost / LightGBM  
- Neural Networks (optional)  

---

## 📊 Evaluation Metrics  
Since the dataset is imbalanced, accuracy is **not reliable**. Instead, we focus on:  
- Precision  
- Recall  
- F1-Score  
- ROC-AUC Curve
